[abstract]
.Abstract
Service that allows customers to submit EDI Orders in the Competec XML format.

== Servers

* Pre-Prod / Test Server: https://edidev.competec.ch/rest/ediservices/
* Production Server: https://edi.competec.ch/rest/ediservices/

== Access

* *HTTP Basic* Authentication _basicAuth_

== Endpoints

[.BrackAlltronXML]
=== Brack.Alltron XML


[.postBrackAlltronOrder]
==== postBrackAlltronOrder

`POST /xml/v1/order`

Endpoint to submit new Brack.Alltron XML order

===== Description

This endpoint accepts Orders in the Competec XML format: https://github.com/Competec/edi-resources/blob/main/Customer/Competec%20XML/Competec_Order_v2.4.1.xsd[Competec_Order_v2.4.1.xsd]

Content-Type must be `text/xml`.

====== Body Parameter

[cols="2,3,1"]
|===
|Name| Description| Required

| CompetecOrder
| Brack.Alltron XML order document (Competec XML format, version 2.4.x) — see <<CompetecOrder>>
| X

|===


===== Responses

.HTTP Response Codes
[cols="2,3,3"]
|===
| Code | Message | Example

| 200
| OK — order accepted.
|

| 400
| Bad request. Content could be parsed, but data is invalid or incomplete.
| `Buyer_party Party_id LPAN is missing.`

| 401
| Unauthorized. Authorization information is missing or invalid.
|

| 406
| Not Acceptable. The provided body is not in the right format (not valid XML).
|

| 500
| Internal Server Error. Unexpected exception.
|

|===

===== Examples

====== Minimal order (one line item)

[source,xml]
----
<?xml version="1.0" encoding="UTF-8"?>
<order>
  <message_header
    source="L01"
    destination="20"
    accesscode=""
    test_flag="0"
    message_type="order"
    document_version_date="03.05.2005"
    document_version="2.30"
    generation_date="01.01.2024"
    generation_time="10:00:00"
    eMail_confirmation="orders@yourcompany.ch"/>
  <order_header>
    <order_reference>
      <BORN>PO-20240101-001</BORN>
      <BORD>01.01.2024</BORD>
    </order_reference>
    <order_party>
      <buyer_party>
        <party_id>
          <LPAN>A123456</LPAN>
        </party_id>
      </buyer_party>
      <ship_to_party>
        <party_id><LPAN/></party_id>
        <name_address>
          <PNA1>Max Mustermann</PNA1>
          <PNA2>Muster GmbH</PNA2>
          <PSTR>Musterstrasse 1</PSTR>
          <PPOB/>
          <PCTY>Zurich</PCTY>
          <PPOC>8001</PPOC>
          <PCTR>CH</PCTR>
        </name_address>
      </ship_to_party>
    </order_party>
    <order_information>
      <additional_information>
        <LNGC>G</LNGC>
        <SHCF>Y</SHCF>
      </additional_information>
    </order_information>
  </order_header>
  <order_body>
    <line_item_number>
      <BLIN>10000001</BLIN>
      <part_number>
        <LITM>1234567</LITM>
        <MITM/>
      </part_number>
      <quantity>
        <quantity_value><OQTY>2</OQTY></quantity_value>
      </quantity>
      <price><UPRC>49.95</UPRC></price>
    </line_item_number>
  </order_body>
</order>
----

[#MessageHeader]
=== _MessageHeader_

XML element: `<message_header>` (all fields are XML _attributes_).

[.fields-MessageHeader]
[cols="2,1,1,2,4"]
|===
| Field Name | XML Attribute | Required | Type | Description

| source
| `source`
| X
| String
| Sender identifier. Customer specific, agreed between parties.

| destination
| `destination`
| X
| String
| Receiver identifier. 10 = Brack, 20 = Alltron, 70 = Jamei

| accesscode
| `accesscode`
| X
| String
| Access code (use empty string)

| test_flag
| `test_flag`
| X
| String
| `0` = production order; `1` = test order (will only be processed in Stage/Test)

| message_type
| `message_type`
| X
| String
| Message type. Fixed value: `order`

| document_version
| `document_version`
| X
| String
| Format version, e.g. `2.30`

| document_version_date
| `document_version_date`
|
| String
| Release date of the format version, e.g. `03.05.2005`

| generation_date
| `generation_date`
| X
| String
| Date the message was generated (DD.MM.YYYY)

| generation_time
| `generation_time`
| X
| String
| Time the message was generated (HH:MM:SS)

| email_confirmation
| `eMail_confirmation`
| X
| String
| E-mail address to receive order confirmation

|===
